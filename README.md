# ESP32-HC-SR04-MG-90-servo-scanning
Custom Ultrasonic scanning Radar project using ESP32, HC-SR04 Ultrasonic sensor and MG-90 2 amount

This project includes that 2 servos,1 ESP32 and 1 HC-SR04 ultrasonic sensor

Step 1:
Adjust your servo pins and sensor pins for HC-SR04

Step 2:
Adjust your scanning angles

Step 3:
Adjust your maximum and minimum distance for object detection

Final step:
Make sure that you check MATLAB script for visuazilation. And verify that your parameters match with MATLAB script
